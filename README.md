# DINO RUN — Endless Adventure

A mobile-friendly 3D endless runner set in a prehistoric world.

## Features
- Four selectable dinosaurs: Tyrannosaurus, Velociraptor, Triceratops and Stegosaurus
- 3D jungle environment, dynamic lighting, fog and shadows
- Lane movement, jumping, sliding, obstacles and collectible shards
- Keyboard, touch-swipe and on-screen mobile controls
- Distance, shard counter, best score and sound effects

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
The production build is generated in `dist/`.
